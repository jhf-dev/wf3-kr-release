# Wind Fantasy 3 한국어 패치

Wind Fantasy 3 비공식 한국어 패치 배포를 위한 저장소입니다.

이 저장소는 게임 본편이나 원본 게임 리소스를 포함하지 않습니다. 사용자가 보유한 Steam 버전 게임 위에 적용하여야 합니다.

## 다운로드

- 안정화 release: `20260817-v1-release` [다운로드](https://github.com/jhf-dev/wf3-kr-release/releases/download/20260817-v1-release/wind3-korean-patch-20260817-v1-release.zip)
- 배포 파일: `wind3-korean-patch-20260817-v1-release.zip`
- SHA-256: `7D336B3B3465ADBAEFBD2B66C930A6125B7A207875C1F6D3DF2B2FF7048A287F`
- 파일 크기: `28,031,896` bytes
- 체크섬 파일: `SHA256SUMS.txt`
- 주요 변경사항: [RELEASE_NOTES.md](RELEASE_NOTES.md)

> 변경 비교 기준은 게시 시점의 직전 latest 안정판 `20260812-v5-release`입니다.

## 사용 방법

1. `wind3-korean-patch-20260817-v1-release.zip`을 다운로드합니다.
2. 원하는 위치에 압축을 풉니다.
3. `Wind3 Korean Patch Launcher.exe`를 실행합니다.
4. `WIND3.EXE`가 있는 게임 폴더를 선택하고 `패치 적용`을 실행합니다.
5. 문제가 생기면 같은 런처의 `원본 복원`으로 되돌립니다.

저해상도 환경에서는 `Wind3 Korean Patch Lite Launcher.exe`를 사용해 패치 적용이 가능합니다.

## 런처 주요 기능

### 런처 메인
<img width="1004" height="719" alt="image" src="https://github.com/user-attachments/assets/72ee919f-ccaa-45e5-aa2d-9d3a7ebbd36c" />

- 화면 설정 : 해상도, 화면 모드를 변경하는 창을 엽니다.
- 입력/오토 : 런처에서 편의를 위해 추가된 키 설정을 변경하거나 ON/OFF하는 창을 엽니다.
- 상태 확인 : 패치의 현재 적용 상태를 확인합니다.
- 패치 적용 : 현재 버전의 패치를 지정된 게임 폴더에 설치합니다.
- 원본 복원 : 현재 버전의 패치를 백업된 적용 전 상태로 되돌립니다.
- 세이브 검사 : 현재 세이브 상태를 검사합니다.
- 세이브 복구 : 세이브의 데이터를 패치에 적합한 상태로 복구합니다.
- 세이브 복원 : 세이브를 패치 적용 전 상태로 되돌립니다.
- 진단 기록 : 로그 및 진단 기록을 기록합니다.
- 오류 보고 ZIP : 버그리포트를 위해 zip 형태로 로그 파일을 묶습니다.
- 버전 정보 : 현재 런처의 버전 정보를 확인합니다.
- 업데이트 : 런처를 최신 버전으로 업데이트합니다.

### 해상도 설정
<img width="548" height="299" alt="image" src="https://github.com/user-attachments/assets/3f5c770e-8f5e-4884-b3ff-6e8b743d9238" />

- 표시 방식 : 전체 창모드, 독점 전체화면, 창모드를 선택합니다.
- 전체 창모드 : alt+tab을 해도 창이 내려가면서 화면이 깜빡이지 않습니다. 800x600을 단순 확대하는 방식으로, 화면이 흐리게 보일 수 있습니다.
- 창모드 : 창모드로 실행합니다. 창/독점 해상도에서 설정한 해상도에 맞춰 창 크기가 바뀝니다.
- 독점 전체화면 : 일반적인 전체화면 모드입니다. 화면 자체의 해상도를 변경하고 해당 화면은 게임 화면만 표시합니다. ALT+TAB 시 창이 내려가며 해상도가 변경되며 화면이 깜빡일 수 있습니다.
- 전체화면 배율 (fit) : 전체 창모드에서 화면 가득 채웁니다.
- 전체화면 배율 (integer) : 화면을 800x600의 정수 배율에 해당하는 크기까지만 확대하고 나머지 영역을 검은색으로 채웁니다. fit 방식에 비해 약간 선명하지만 게임화면 영역이 작아집니다.
- 자동화 테스트용 마우스 모드 : 개발용 기능으로, 안정성을 위해 켜는 것을 권장하지 않습니다.

### 입력/오토 설정
<img width="548" height="559" alt="image" src="https://github.com/user-attachments/assets/9d3cb7d4-9c89-4dbc-93ee-df1ae65a5de0" />

- 키보드 카메라 조작 사용 : 활성화하면 숫자 키패드 대신 설정한 키를 사용해 인게임 카메라를 조작할 수 있습니다.
- 자동 기능 사용 : 활성화하면 `/` 키를 눌러서 선택한 캐릭터가 1회 자동으로 행동하게 만들 수 있습니다.
- 전투 즉시 승리 : 활성화하면 F3 키를 눌러서 현재 전투를 즉시 승리하게 만들 수 있습니다. 개발용 기능입니다.

### WindConfig.exe
<img width="548" height="299" alt="image" src="https://github.com/user-attachments/assets/35fbbf1c-ca12-4dbe-97c5-c2e0a436bf71" />

## 사용 전 주의사항

- 패치 적용 전에는 게임을 완전히 종료해 주세요.
- 중요한 저장 데이터는 별도로 백업하는 것을 권장합니다.
- 이 패치는 비공식 개인 한국어 패치이며 모든 PC 환경에서 동일한 동작을 보장하지 않습니다.

## 포함하지 않는 것

- Wind Fantasy 3 게임 실행 파일
- 원본 게임 리소스 전체
- 사용자의 저장 데이터
- 로컬 테스트 로그와 개발 중간 산출물
